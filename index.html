Pomodoro Study

Plataforma voltada para organização e produtividade nos estudos, baseada na técnica Pomodoro. O projeto conta com uma área de autenticação para usuários, incluindo funcionalidades de login, cadastro e recuperação de senha. A aplicação foi desenvolvida com o objetivo de auxiliar estudantes na organização de sua rotina e no gerenciamento do tempo dedicado aos estudos, aplicando um dos métodos mais conhecidos de gestão de tempo e foco.

Documento Comercial

Sistema desenvolvido para criação e gerenciamento de documentos comerciais. A aplicação permite inserir informações de clientes, data de emissão, produtos ou serviços, quantidades, valores unitários e observações. A partir dos dados cadastrados, o sistema realiza os cálculos necessários para apresentar os valores do documento e disponibiliza recursos para visualização, impressão e geração do documento em formato PDF, proporcionando uma solução prática para a elaboração de documentos comerciais.

Operações Matemáticas

Projeto desenvolvido com foco na aplicação de testes unitários em JavaScript. A aplicação utiliza uma função matemática de multiplicação como base para demonstrar como diferentes cenários podem ser testados automaticamente, verificando se os resultados obtidos correspondem aos valores esperados. O projeto também apresenta os resultados dos testes e permite acompanhar a execução através do console do navegador, servindo como demonstração prática de conceitos de testes automatizados e validação de código.

Mangás Brasil

Plataforma web dedicada ao universo dos mangás, desenvolvida para proporcionar uma experiência de navegação e descoberta de diferentes obras. O projeto apresenta recursos como busca, categorias, mangás populares, informações sobre o conteúdo disponível, área de assinatura, blog e parceiros. A interface foi estruturada para simular uma plataforma especializada, reunindo diferentes seções relacionadas à leitura, descoberta e acompanhamento de mangás em um único ambiente.

ProjetoAPI

Aplicação desenvolvida para demonstrar na prática o consumo e a integração de APIs (Application Programming Interfaces) em aplicações web. O projeto reúne diferentes funcionalidades que utilizam serviços externos para realizar consultas e obter informações, incluindo dados relacionados a clima, cotação do dólar, receitas, músicas, CEP e outros serviços. Dessa forma, o projeto demonstra como uma aplicação pode se comunicar com diferentes APIs e utilizar os dados retornados para fornecer funcionalidades interativas ao usuário.

Aula-LocalStorage

Aplicação desenvolvida para demonstrar o funcionamento do LocalStorage do navegador através de uma lista de tarefas. O projeto permite ao usuário adicionar e gerenciar tarefas diretamente pela interface, utilizando o armazenamento local para preservar as informações no navegador. A aplicação foi criada como uma demonstração prática do uso de recursos de armazenamento do lado do cliente, mostrando como dados podem ser salvos e recuperados sem a necessidade de um banco de dados ou servidor externo.

Drag and Drop

Aplicação desenvolvida como um organizador semanal de estudos utilizando a funcionalidade Drag and Drop. O projeto apresenta os dias da semana e diferentes disciplinas, permitindo que o usuário organize visualmente suas matérias de acordo com a rotina desejada. A interação de arrastar e soltar torna a organização mais intuitiva e demonstra, na prática, a utilização de eventos e funcionalidades de Drag and Drop em aplicações web para criar interfaces interativas e dinâmicas.
