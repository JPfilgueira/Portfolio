⚙️ Sobre o projeto <br>
Este é o meu portfólio pessoal, um site desenvolvido para apresentar quem eu sou, minhas tecnologias e minha trajetória. O site foi construído com HTML, CSS e JavaScript puros, sem frameworks. Ele conta com alternância entre tema claro e escuro, e seções com animações e transições suaves. <br> <br>

📁 Portfolio\ <br>
├─ index.html -> Página principal do portfólio <br>
├─ style.css / globals.css -> Estilização do site <br>
└─ script.js -> Interações e animações <br> <br>

🧩 Funcionamento <br>
O site é dividido em seções: Introdução, Tecnologias, Histórico e Contato. Na introdução, o usuário pode clicar em um botão para revelar uma ilustração animada sobre mim. Também é possível alternar entre tema claro e escuro através do ícone no cabeçalho. <br> <br>

🔗 Links e APIs externas
- Google Fonts -> Utilizado para carregar as fontes do site (Inter, Outfit e IBM Plex Mono) <br>
- Devicon -> Biblioteca de ícones usada para representar tecnologias e redes sociais (GitHub e LinkedIn) <br>
