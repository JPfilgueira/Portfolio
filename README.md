🌐 Portfólio <br>

Este é o meu portfólio pessoal, um site desenvolvido para apresentar quem eu sou, minhas tecnologias e minha trajetória. <br> <br>

⚙️ Sobre o projeto <br>
O site foi construído com HTML, CSS e JavaScript puros, sem frameworks. Ele conta com um loading screen inicial, alternância entre tema claro e escuro, e seções com animações e transições suaves. <br> <br>

📁 Portfolio\ <br>
├─ index.html -> Página principal do portfólio <br>
├─ loading.html -> Tela de carregamento inicial <br>
├─ style.css / loading.css / globals.css -> Estilização do site <br>
└─ script.js / loading.js -> Interações e animações <br>
